# Layer Overview
We've built six raw tables from the sources: 3 from an ERP source and 3 from a CRM source. There's six tables in the Bronze layer which then get cleaned up and transformed in the Silver layer. Finally, they are joined and aggregated in the Gold layer and stored as Views, ready for analysis.
